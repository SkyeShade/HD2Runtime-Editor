# 0.10.0 local development — Runtime 0.32.0 enemy controls

Local branch: `local/0.32.0-enemy-structures`. Requires the local HD2Runtime
0.32.0 build containing enemy controls. Nothing is published or installed by the
build script.

Import `build/HD2REditor-0.10.0.zip` and the matching Runtime ZIP into your mod
manager, replacing their older installed versions. Start the game and press F8.

- Enemies: all 1,178 entity targets, including 429 structures, plus recovered
  damage-zone names, typed attacks, size, shield, jammer and spawner settings.
- Other Entities: unresolved classes, mounted components and HiveMind/Bughole
  controllers. Unknown identities retain their build-specific names.
- Mission Difficulty: ten difficulty rows, budgets and cooldowns.
- Spawn Rosters: 191 entries across five rosters, weights by difficulty.
- Spawn Compositions: 452 rows, weights, eligibility bounds, counts, enemy
  candidates and emission schedules.
- Demolition Templates: shared required force; unavailable sentinels stay read-only.
- Destruction Models: 1,641 models with their ordered destruction stages.

Use the normal pending edits, Apply, Reset, presets and Export flows. Old enemy
field keys remain valid. Exported director targets use the Runtime's nested
`hd2.enemies` API and include its required acknowledgements. Shared fields keep
the same identity across pages and sessions.

Spawn source edits require Ship state and affect future compilation. Creation
scale does not resize existing enemies. Passenger footprints are bounds, not
confirmed ship manifests. Zero weights suppress ordinary picks only. Demolition
forces are shared thresholds, not independent values per structure. Unknown
semantics and fields whose native default cannot be restored stay inspectable
and locked.

Validation uses the actual Lua VM, Runtime validators and simulated write path;
it does not establish live gameplay effects. The current development Runtime
lacks some weapon features expected by the editor release: the existing Gas
status-slot and AC-8 Flak outline tests also fail with the unchanged editor.
Those pre-existing weapon compatibility gaps are not changed by this branch.
The Status Effects category also reports unavailable on this Runtime checkout.

The new category audit builds 111,540 rows (including inspection information);
all 42,175 editable rows pass the Runtime validator. Representative enemy and
director fields pass apply/reset, mod takeover, export and overlay-rendering tests.
